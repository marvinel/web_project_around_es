# Around the U.S.

## Descripción
Aplicación web interactiva que permite explorar lugares de Estados Unidos mediante tarjetas con imágenes y nombres de ubicaciones.

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Visualización de tarjetas.
- Edición del perfil.
- Agregar y eliminar tarjetas.
- Dar "Me gusta".
- Diseño responsive.
